FW · Wireframe design system · Issue A

A black & white kit for mocking up Forma site-design concepts

An original grayscale component library inspired by the UX grammar of Autodesk Forma — canvas-first layout, docked panels, live metrics, rapid analyses. Built on a strict 8px grid. Patterns stand in for semantic color. Copy any component into a new page and compose.

Page skeleton

Every mockup page starts from this skeleton. The icon sprite block (see view-source of this page, first child of <body>) must be pasted in for <use href="#fw-i-…"> to resolve over file://.

  <link rel="stylesheet" href="css/components.css">
  <link rel="stylesheet" href="css/app.css">
</head>
<body>
  <!-- paste the FW sprite block here -->
  <!-- compose .fw-* components -->
  <script src="js/shared.js"></script>
</body>
</html>
Kit rules
  • Heights, row heights and layout gaps sit on the 8px grid; 4px is allowed only inside a component. Press g on any page to overlay the grid.
  • No chromatic color. Meaning is carried by the grayscale ramp and by patterns — hatch, dots, crosshatch — always with a labeled legend.
  • Components carry no external margins; parents own spacing via flex/grid gap.
  • JavaScript is optional. Pose states in markup with .is-open, .is-selected, aria-checked.
  • Presenter aid: every click flashes a red ring around the clicked control — the kit's single chromatic element, so narration can't be mistaken for product UI. Press r to toggle.
  • Use Forma vocabulary: proposal, base layer, site limit, function, GFA, rapid vs detailed analysis.
